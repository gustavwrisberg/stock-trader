    How it decides

    Quality, from the skill

    Once a week the bot pulls each company's annual statements and computes the ratios the stock-analysis skill asks for: return on capital, margins, cash conversion, leverage, growth, dilution and valuation. The skill's own score.py grades each one against benchmarks for that company's sector, so a bank is never judged by software margins. Red-flag gates cap or veto a score, for example when cash flow has trailed reported profit for three years.

    Timing, from momentum

    Every weekday after the US close it measures 12-month price momentum, skipping the latest month, and checks the stock is above its 200-day average. Skill-scored ranks stocks half on skill score and half on momentum, and only buys names scoring 5 or more. Momentum only ignores the skill entirely: it is the control that shows whether the fundamentals help.

    Trading rules

    Each portfolio holds 6 stocks at equal weight. A holding is kept while it ranks in the top 10, which avoids churning on small moves. Weights reset on the first run of each month. Every trade pays 0.10% in costs.

    The data is Yahoo Finance via yfinance. The skill treats that as an aggregator: fine for a screen like this, never a source of record. Scores cover only the measurable parts of the skill (no moat, governance or management judgement), so they are labelled indicative. Paper money only. This is an experiment, not investment advice.
